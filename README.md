# Network Monitoring Dashboard

## Overview
A Java and Spring Boot based Network Monitoring Dashboard for analyzing network logs, generating statistics, and visualizing network performance.

## Tech Stack
- Java
- Spring Boot
- MySQL
- CSV Log Analysis
- Chart.js
- REST API

## Planned Features
- CSV Log Upload
- Network Statistics Dashboard
- Device Monitoring
- Packet Loss Analysis
- Search & Filter Logs
- Authentication
- Report Generation

🚧 Currently under development.
